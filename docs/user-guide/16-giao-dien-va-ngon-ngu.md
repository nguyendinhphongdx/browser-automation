# Giao diện & Ngôn ngữ

[← Về mục lục](../README.md)

Vào **Cài đặt** (`Ctrl+,`):

## Giao diện (Theme)

- **Sáng** / **Tối** / **Theo hệ thống** — chọn "Theo hệ thống" thì app tự đổi theo cài đặt sáng/tối của hệ điều hành, kể cả khi hệ điều hành đổi theme lúc app đang mở (không cần khởi động lại)
- Lựa chọn được nhớ lại cho lần mở app sau

## Ngôn ngữ

- **Tiếng Việt** / **English** — đổi ngay lập tức, không cần khởi động lại app
- Áp dụng cho toàn bộ nhãn, nút bấm, thông báo trong giao diện

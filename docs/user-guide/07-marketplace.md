# Marketplace

[← Về mục lục](../README.md)

## Xem workflow có sẵn

- Vào **Marketplace**
- Tìm kiếm theo tên hoặc mô tả
- Lọc theo loại: Tất cả, Visual, Code

## Import / Export (local)

- **Import**: Nhấn "Import Workflow" → chọn file JSON đã export trước đó
- **Export**: Nhấn "Xuất file" trên card workflow để lưu ra file JSON, chia sẻ thủ công (email, chat...)

## Marketplace online

Khi đã [kết nối server](08-ket-noi-server.md) và đăng nhập:

- Upload workflow lên cộng đồng (cần server duyệt trước khi hiển thị công khai)
- Người dùng khác tìm kiếm, tải về, đánh giá (1-5 sao) và nhận xét
- Mua bán workflow trả phí, chia doanh thu 70/30 giữa người tạo và nền tảng
- Xem thống kê doanh thu cá nhân ở trang **Creator**

Tiếp theo: [Kết nối Server →](08-ket-noi-server.md)

# Ghi lại thao tác (Record Mode)

[← Về mục lục](../README.md)

Record Mode biến thao tác tay của bạn trên trình duyệt thật thành 1 workflow kéo-thả, không cần tự dựng node thủ công.

## Cách dùng

1. Mở browser cho một profile (nhấn **Play** ở trang Profiles)
2. Vào **Automation**
3. Ở panel **"Ghi lại thao tác"** bên trái dưới:
   - Chọn profile đang mở browser
   - Nhấn **"Bắt đầu ghi"**
4. Thao tác bình thường trên browser đó: click, nhập text, điều hướng, cuộn...
5. Mỗi thao tác hiện ra **real-time** trong panel khi bạn làm
6. Nhấn **"Dừng ghi"** khi xong
7. Nhấn **"Lưu workflow"** để chuyển toàn bộ thao tác đã ghi thành node trên canvas

## Khi nào nên dùng

- Khi bạn chưa quen với các loại node và muốn có 1 workflow khởi điểm nhanh
- Khi thao tác lặp lại đơn giản (điền form, click qua nhiều bước) mà tự dựng node bằng tay sẽ mất thời gian hơn

## Sau khi ghi xong

Workflow sinh ra từ Record Mode vẫn là workflow kéo-thả bình thường — bạn có thể chỉnh sửa, thêm node điều kiện/vòng lặp, hoặc nhờ [AI Agent](06-ai-agent.md) tinh chỉnh thêm.

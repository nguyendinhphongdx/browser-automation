# Phím tắt

[← Về mục lục](../README.md)

| Phím tắt | Chức năng |
|----------|-----------|
| `Ctrl/Cmd+N` | Tạo profile mới |
| `Ctrl/Cmd+S` | Lưu workflow |
| `Ctrl/Cmd+Shift+R` | Chạy workflow |
| `Ctrl/Cmd+F` | Tìm kiếm |
| `Ctrl/Cmd+,` | Mở cài đặt |
| `Ctrl/Cmd+1` | Chuyển sang Profiles |
| `Ctrl/Cmd+2` | Chuyển sang Automation |
| `Ctrl/Cmd+3` | Chuyển sang Tài nguyên |
| `Ctrl/Cmd+4` | Chuyển sang Marketplace |
| `Ctrl/Cmd+5` | Chuyển sang Cài đặt |
| `Delete` / `Backspace` | Xoá node/cạnh đã chọn trên canvas |

> Trên macOS, `Cmd` đóng vai trò như `Ctrl` cho các phím tắt trên.
